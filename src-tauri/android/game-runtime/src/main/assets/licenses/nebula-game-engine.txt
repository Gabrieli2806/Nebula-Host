The unmodified source is kept in src-tauri/android/engine as a Git submodule.
Nebula adaptations are in src-tauri/android/game-runtime (package
net.g2806.nebula.game), namespace-bypass,
and the generated Android project's GamePlugin.kt. build.gradle documents the
source transformations used to integrate the engine and remove token logging,
and the build-time renaming of the product name in its visible string resources.
The upstream launcher, account, and downloader screens are not entry points.

The engine's third-party libraries, Java components, renderer and native
libraries retain their own licenses. See the upstream README and source tree
at the revision above for the original attribution and component sources.
OpenJDK runtimes include their legal notices under game-jre/<major>/legal.
Runtime source: https://github.com/AngelAuraMC/angelauramc-openjdk-build
The SHA-256 release asset pins are recorded in scripts/android-game-jre.mjs.
